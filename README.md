
# FIT3179 – Data Visualisation II

## Victorian Local Government Services

An interactive data visualisation project exploring local government services across Victoria's 79 councils. The website examines patterns and differences in waste management, public libraries, aquatic facility usage, and community consultation satisfaction.

### Live Website

[View Interactive Visualisation](https://jvnaash.github.io/FIT3179_DV2_34828532/)

### Project Overview

This project presents 12 interactive visualisations to explore geographical differences, trends over time, service usage, and variations between Victorian councils.

The visualisations include maps, a heatmap, slope chart, violin plot, lollipop chart, bump chart, empirical cumulative distribution function (ECDF), box plot, beeswarm plot, and parallel coordinates plot.

### Technologies Used

- HTML, CSS and JavaScript
- Vega and Vega-Lite
- Vega-Embed
- CSV and GeoJSON datasets
- GitHub Pages

### Data Sources

- Victorian Local Government Performance Reporting Framework (LGPRF)
- Environment Protection Authority Victoria (EPA)
- Australian Bureau of Statistics (ABS)
